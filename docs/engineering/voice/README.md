# Miles Voice Library v1.0

## Purpose
The Miles Voice Library is a planning and reference module for Miles 2.0. It does not assume any particular TTS engine, model, voice, or hardware configuration has already been selected.

Its job is to create a disciplined, repeatable way to collect candidates, test them under the same conditions, document technical performance, evaluate personality fit, preserve rejected options, allow Miles meaningful input into the eventual choice, and avoid committing money or compute before evidence supports the decision.

## Core principle
**Do not decide Miles's permanent voice before Miles can participate in the decision and before the technical options have been tested.**

Bryan controls which technologies, models, licenses, and hardware are acceptable to install. Within that safe and practical candidate set, Miles should eventually be allowed to express and explain a preference.

The final decision should consider three distinct sources of evidence:
1. Bryan's evaluation.
2. Miles's stated preference and reasoning.
3. Objective benchmark results.

No single source automatically overrides the others.

## Engineering alignment
- Modular
- Offline-first
- Reversible
- Evidence-driven
- Cost-conscious
- Measurable
- Documented
- Easy to expand later

## Suggested workflow
1. Identify a compatible TTS engine.
2. Add candidate voices without declaring a winner.
3. Generate the same benchmark script with each candidate.
4. Record hardware/software conditions.
5. Evaluate listening quality and personality fit.
6. Measure latency, memory use, CPU load, stability, and offline behavior.
7. Let Miles review candidates when technically possible.
8. Record Bryan's preference, Miles's preference, and benchmark results separately.
9. Select a temporary approved voice if needed.
10. Revisit the decision if better evidence or technology appears.
